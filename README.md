## The Zotero toolbox

Small extensions for the steps between finding a paper and making it part of your work.

| | Project | What it connects |
| :---: | :--- | :--- |
| **01** | **[Author Scholar](https://github.com/kimstitute/zotero-author-search-plugin)** | A paper's authors → automatically matched Scholar profiles, yearly citations, and ranked publications |
| **02** | **[Connected Papers](https://github.com/kimstitute/zotero-connected-paper-plugin)** | A selected paper → related-research graphs in a Zotero tab |
| **03** | **[Moonlight](https://github.com/kimstitute/zotero-moonlight-plugin)** | A paper's online address → reading in Moonlight, from Zotero or a browser |
| **04** | **[Obsidian Connector](https://github.com/kimstitute/zotero-obsidian-connector)** | A Zotero library → linked Markdown literature notes and a browsable dashboard |

<p><sub>Independent integrations. Each repository includes its own installation guide and compatibility notes.</sub></p>
